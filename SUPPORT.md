# Getting help

- **Documentation:** [bever.dev](https://bever.dev) has guides, a tutorial, and references for the language, CLI, HTTP API, and SDK.
- **Questions and bugs:** open an issue in the [repository](https://github.com/bever-team/.github/blob/main/CONTRIBUTING.md#where-things-live) that fits. For bugs, include a minimal `.bev` model and the command you ran.
- **Security issues:** follow the [security policy](SECURITY.md).
